## ✨ 功能特性

### 🛒 商城端（已开源）

| 模块 | 功能点 |
|------|--------|
| **首页** | Banner轮播、分类导航、热销推荐、限时特惠、新闻公告 |
| **商品中心** | 分类筛选、多维搜索、排序、商品卡片展示 |
| **商品详情** | 图片轮播、规格选择、批发价阶梯、用户评价、相关推荐 |
| **购物车** | 增删改查、数量调整、批量操作、价格实时计算 |
| **结算下单** | 单页结算、邮箱接收、多种支付方式、优惠券抵扣 |
| **订单管理** | 订单列表、详情查看、卡密显示、一键复制 |
| **订单查询** | 无需登录、凭订单号+邮箱查询 |
| **用户中心** | 个人资料、我的订单、收藏夹、消息通知 |
| **帮助中心** | FAQ、使用教程、联系方式 |

### 💰 批发价系统
- 支持多级阶梯定价（如：1-9件98元，10-49件95元，50+件90元）
- 根据购买数量自动计算批发价
- 实时显示当前适用价格和节省金额
- 购物车自动应用批发价

### 🎨 界面设计
- 现代简约设计风格，参考主流电商平台
- 响应式布局，兼容桌面和移动端
- 暗色模式支持
- 流畅的动画和过渡效果
- 骨架屏加载、Toast提示等交互细节

## 🚀 快速开始

### 环境要求

- **Node.js** >= 18.0.0
- **npm** >= 9.0.0

### 安装与运行

```bash
# 克隆项目
git clone https://github.com/your-username/card-mall-demo.git
cd card-mall-demo

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

### Docker 部署

```bash
# 构建项目
npm run build

# 启动容器
docker compose up -d

# 访问 http://your-server-ip:39527
```
